my_agents — Local AI Cognitive Workspace
A self-hosted multi-agent AI workspace that runs entirely on your local machine using Ollama. Features dual-agent reasoning (Agent-A plans, Agent-B reviews), persistent sessions, file-aware coding, and an MCP tool ecosystem — all with ChatGPT-level UX in your browser.
Key Features
🔒 100% Local — No cloud, no API keys, no data leaves your machine
🧠 Dual-Agent Loop — Plan → Review → Iterate → Implement workflow
⚡ Single-Runtime Safe — Only one model active at a time, zero VRAM crashes
📁 Workspace-Aware — Agents read/write files in your project folder
🛠️ MCP Tools — 14 built-in tools + upload custom + AI-generated
💾 Persistent Sessions — SQLite + event sourcing, survive crashes/restarts
⏯️ Pause/Resume/Stop — Full control during generation
📎 File Attachments — Drag, drop, paste files into prompts
🎨 ChatGPT-Grade UX — Streaming, code blocks, themes, 60fps
Stack: FastAPI + React/Vite + SQLite + Ollama
